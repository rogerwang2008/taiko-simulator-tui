# 太鼓模拟器 (taiko-simulator-tui)

把键盘从左到右切成四个区，敲下任意键即刻发声：鼓面 (don) 或鼓边 (ka)，送到左或右声道。
界面用 Textual 绘制，可视化调整四区的分界，改动即时写入本地配置文件。

```
uv run taiko-simulator-tui
```

## 四个区

| 区 | 声音 | 声道 | 默认按键 |
| --- | --- | --- | --- |
| 左鼓边 | rim (ka) | ← 左 | `1 2 3 4 Q W E A S D Z X` |
| 左鼓面 | center (don) | ← 左 | `5 6 7 R T Y F G H C V B` |
| 右鼓面 | center (don) | 右 → | `8 9 0 U I O J K L N M , .` |
| 右鼓边 | rim (ka) | 右 → | `- = P [ ] \ ; ' /` |

分区按每个键的**物理横向位置**（含各行交错偏移）划分，所以四个区是键盘上真实的四条竖带，
而不是四组零散的键。

## 按键

| 键 | 作用 |
| --- | --- |
| 布局内任意键 | 敲击对应区，立即发声并闪烁反馈 |
| `↑` / `↓` | 选择要调整的边界 `^1` / `^2` / `^3` |
| `←` / `→` | 以 0.25 键位为步长移动选中的边界 |
| `Ctrl+R` | 恢复默认分区 |
| `Esc` / `Ctrl+Q` | 退出 |

边界每次移动都会立刻保存，无需确认。

## 配置

`platformdirs` 的用户配置目录下的 `config.json`，本机为：

```
C:\Users\hp\AppData\Local\taiko-simulator-tui\config.json
```

内容只有分区边界（键位单位，键盘横向范围 0–12.5）：

```json
{ "version": 1, "boundaries": [3.25, 6.25, 9.5] }
```

文件损坏或数值非法时自动回退默认分区。

## 低延迟

按键到出声的实测预算（Headphone Realtek / WASAPI 共享模式 / 48 kHz）：

- 击鼓热路径（`on_key` → 写入环形缓冲）：中位数 **0.04 ms**，无内存分配、不加锁竞争
- 设备输出缓冲：**22.0 ms**（WASAPI 共享模式在本机的下限，`latency="low"` 与独占模式之外无法再降）
- 回调成簇触发，拾取新写入的数据平均再等 **~5 ms**

合计约 **25–30 ms**。独占模式实测可到 4.3 ms，但会独占音频设备导致其他应用静音，本项目刻意不用。

样本加载时做了三件事，都是为了让「敲击瞬间」真的对齐按键瞬间：

1. **裁掉前导静音** —— 原始 mp3 每次敲击前有约 70 ms 静音，不裁就等于凭空加 70 ms 延迟
2. **裁掉尾部静音** —— 11.08 s 的素材里有效声音只有 1.5–1.8 s
3. **峰值归一到 0.6** —— 原始 rim 峰值只有 center 的四分之一，不归一鼓边几乎听不见；
   留出余量是因为左右手经常同时击打

单个常驻输出流 + 环形缓冲，触发时把预先分好声道的样本加性写入读指针处，
所以并发敲击自然混音，快速连打时由回调里的 `np.clip` 限幅。

## 结构

```
src/taiko_simulator_tui/
  audio.py      解码 / 裁剪 / 归一 / 重采样，环形缓冲与输出流
  keyboard.py   键盘布局、交错偏移、四分区解析与边界钳制
  config.py     配置读写与校验
  app.py        Textual 界面
  assets/audio/ center1.mp3 鼓面、rim1.mp3 鼓边
```
